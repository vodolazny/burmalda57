# 📚 Электронный дневник obr57 (burmalda57)

Неофициальный Android-клиент электронного дневника Орловской области ([obr57.ru](https://obr57.ru/gis)).
Написан на **Rust + [Slint](https://slint.dev)** (нативный аппаратный рендер FemtoVG / OpenGL ES через EGL), сборка через Gradle.

![platform](https://img.shields.io/badge/platform-Android%208.0%2B-brightgreen)
![arch](https://img.shields.io/badge/arch-arm64--v8a-blue)
![license](https://img.shields.io/badge/license-Apache--2.0-lightgrey)

> ⚠️ **Неофициальный проект.** Не связан с Департаментом образования Орловской области, порталом Госуслуг/ЕСИА или разработчиками официального дневника. Используется на свой страх и риск.
> ⚠️ **БЕТА** Приложение активно развивается, возможны сбои и ошибки.

## ✨ Возможности

- 📊 **Оценки по предметам**: четверти/периоды, коэффициенты веса оценок, точный расчёт взвешенного среднего балла.
- 🎯 **Симулятор среднего балла**: интерактивный калькулятор — проверяй, сколько и каких оценок нужно получить для желаемой итоговой.
- 📈 **Графики успеваемости**: визуализация динамики оценок по каждому предмету за весь учебный год с границами четвертей.
- 📅 **Дневник и расписание**: уроки, кабинеты, имена учителей, темы занятий и домашние задания с отметками о выполнении.
- 📝 **Заметки к урокам**: возможность оставлять личные комментарии и напоминания к любому уроку (шифруются локально на устройстве).
- 🗓️ **Личные события**: добавление внеурочных занятий, кружков и секций прямо в сетку расписания.
- 📆 **Удобный календарь**: быстрый переход к любому учебному дню через встроенный календарь.
- 👨‍👩‍👧 **Кабинет родителя**: поддержка родительских аккаунтов с быстрым переключением между детьми на лету.
- 👁️ **Скрытие предметов**: возможность исключить неактуальные предметы из общего списка.
- 🎮 **Демо-режим**: полноценный осмотр всего интерфейса и возможностей без авторизации через Госуслуги.
- 👤 **Профиль**: ФИО, школа, класс, установка и удаление аватара.
- 🔔 **Умные уведомления**: фоновая проверка новых оценок через **Android WorkManager** с настраиваемым расписанием и энергосбережением.
- 🔄 **Автопроверка обновлений**: ненавязчивое оповещение при появлении новой версии в GitHub Releases с прямой ссылкой на скачивание.

## 🔒 Приватность и безопасность

### «А если я не доверяю Госуслугам / стороннему приложению?»

Это честный вопрос, поэтому коротко о том, как всё устроено:

- **Приложение полностью открытое (open source).** Весь код в этом репозитории — можно прочитать, проверить и собрать самому (см. [Сборка из исходников](#-сборка-из-исходников)). Если не доверяешь готовому APK — не ставь его, а собери бинарь сам из этих же исходников.
- **Пароль от Госуслуг приложение не видит и не хранит.** Вход через **ЕСИА** открывается в системном WebView **на официальном портале ЕСИА** (в WebView открывается точно та же страница, что и в оригинальном региональном приложении) — логин и пароль вводятся на настоящей странице Госуслуг, а не в полях стороннего приложения.
- **Хранится только результат входа** — сессионная кука и `apikey`, причём исключительно в зашифрованном виде. Используется envelope-шифрование: данные шифруются ключом AES-256-GCM, а сам ключ лежит в **аппаратном хранилище Android Keystore** (StrongBox / TEE) и физически не покидает устройство.
- **Данные уходят только на официальные серверы** регионального дневника (`mp2.obr57.ru`). Никаких сторонних бэкендов, прокси или серверов-посредников у приложения нет.
- **Офлайн-работа**: загруженные расписание и оценки кешируются в зашифрованном виде, приложение можно открывать без интернета. При выходе из аккаунта все сессионные кеши и аватарки безвозвратно удаляются с диска.
- **Единственное внешнее исключение — Sentry** (сбор отчётов о падениях приложения). Он не собирает твои оценки, логины или личные данные (PII отключен), только технические стектрейсы о крашах. Его можно полностью выключить, собрав приложение без него — см. [Отключить Sentry](#-отключить-sentry).
- Никакой рекламы, трекеров и аналитики поведения.

## 🛠️ Технологии

| Слой | Что используется |
|------|------------------|
| UI | [Slint 1.8](https://slint.dev) (нативный рендер `FemtoVG` / OpenGL ES поверх EGL через `glutin`) |
| Логика/сеть/крипта | Rust (`cdylib`, собирается через `cargo-ndk`) |
| Платформа | `android-activity` (NativeActivity) |
| Фоновые задачи | `Android WorkManager` (GradesWorker на Kotlin) |
| HTTP/TLS | `reqwest` + `rustls` (крипто-провайдер `ring`) |
| Async Runtime | `tokio` (многопоточный рантайм под мобильные платформы) |
| Крашлитика | `sentry` (транспорт `ureq` + `rustls`) |
| Kotlin-хелперы | Android Keystore (аппаратное шифрование), системные пуш-уведомления, выбор аватара, вход через ЕСИА WebView |

## 📦 Сборка из исходников

### Быстрый способ — скрипт сборки

В корне репозитория лежат `build.sh` (Linux/macOS) и `build.ps1` (Windows). Они сами:
- проверяют и при необходимости ставят (спрашивая подтверждение на каждый шаг) Rust, Android-таргет, `cargo-ndk`, JDK 17, Android SDK/NDK, build-tools;
- если `ANDROID_HOME` вообще не задан — скачивают Android SDK с нуля;
- собирают APK;
- в конце предлагают установить его на подключённое по ADB устройство.

**Linux / macOS:**
```bash
chmod +x build.sh
./build.sh              # debug-сборка (по умолчанию)
./build.sh --release    # release-сборка (нужен keystore.properties, см. ниже)
./build.sh --yes        # не спрашивать подтверждения на установку зависимостей
```

**Windows (PowerShell):**
```powershell
# разово, если скрипт скачан не через git clone, а как zip-архив:
Unblock-File -Path .\build.ps1

.\build.ps1              # debug-сборка
.\build.ps1 -Release     # release-сборка
.\build.ps1 -Yes         # без подтверждений
```
Если PowerShell ругается на политику выполнения — либо разово:
```powershell
powershell -ExecutionPolicy Bypass -File .\build.ps1
```
либо один раз для своего пользователя:
```powershell
Set-ExecutionPolicy RemoteSigned -Scope CurrentUser
```

Готовый APK появится в `app/build/outputs/apk/debug/` или `app/build/outputs/apk/release/`.

### Требования для ручной сборки

- **Rust** (stable) + Android-таргет:
  ```bash
  rustup target add aarch64-linux-android
  ```
- **cargo-ndk**:
  ```bash
  cargo install cargo-ndk
  ```
- **Android SDK** — platform `android-34`, build-tools `34.0.0`
- **Android NDK** — r29 (`29.0.14206865`) или совместимый
- **JDK 17**
- Устройство или эмулятор **arm64-v8a**, Android **8.0+** (API 26+)

### Переменные окружения

```bash
export ANDROID_HOME=/opt/android-sdk
export ANDROID_NDK_HOME=$ANDROID_HOME/ndk/29.0.14206865
export JAVA_HOME=/usr/lib/jvm/java-17-openjdk
```

> Нативную библиотеку `.so` Gradle собирает автоматически: перед упаковкой APK запускается задача `cargoNdkBuild` (см. `app/build.gradle`), которая вызывает `cargo-ndk`. Отдельно вручную вызывать компиляцию Rust не требуется.

### Debug-сборка

```bash
./gradlew :app:assembleDebug
adb install -r app/build/outputs/apk/debug/app-debug.apk
```

### Release-сборка (с подписью)

1. Создай свой keystore (**один раз, храни и бэкапь надёжно** — тем же ключом придётся подписывать все последующие обновления):
   ```bash
   keytool -genkeypair -v \
     -keystore my-release.jks \
     -alias my-alias \
     -keyalg RSA -keysize 4096 -validity 10000
   ```
2. Создай в корне проекта `keystore.properties`:
   ```properties
   storeFile=../my-release.jks
   storePassword=ПАРОЛЬ_KEYSTORE
   keyAlias=my-alias
   keyPassword=ПАРОЛЬ_КЛЮЧА
   ```
3. Собери:
   ```bash
   ./gradlew :app:assembleRelease
   ```
   Готовый файл: `app/build/outputs/apk/release/app-release.apk`
4. Проверь подпись:
   ```bash
   $ANDROID_HOME/build-tools/34.0.0/apksigner verify --print-certs \
     app/build/outputs/apk/release/app-release.apk
   ```

## 🧯 Отключить Sentry

Если не хочешь, чтобы приложение отправляло отчёты о сбоях:

1. В `rust/Cargo.toml` убери зависимость `sentry`.
2. В `rust/src/lib.rs` удали блок инициализации Sentry (`sentry::init(...)` и связанный `_guard`).
3. Пересобери — приложение будет работать полностью автономно без телеметрии.
